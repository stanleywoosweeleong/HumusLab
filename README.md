# 沃土有机质 HumusLab

Trilingual (中文 / English / Malay) offline app on soil organic matter and humic substances.

Live: https://stanleywoosweeleong.github.io/HumusLab/

## Files

- `index.html` — the whole app (markup, styles, logic, content, references)
- `sw.js` — self-updating service worker; no version number to bump
- `manifest.webmanifest`, `icons/` — install icons and the WhatsApp link-preview image

## Updating

Edit `index.html` and push. GitHub Pages publishes in a minute or two. Installed
copies open from the saved version, check for changes, and show a
"new version is ready" bar with a Refresh button.
